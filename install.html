You've read about all of this. You haven't done any of it.

  • You use Claude in a browser tab and suspect you're using 5% of it.
  • Your website's source code isn't anywhere you can find.
  • You've heard "just put it in GitHub" and nodded.
  • You've watched somebody demo Claude Code and thought that looks like it's for engineers.
  • You have three tasks a week that are obviously automatable and still doing them by hand.

Five things, one day, in order.

1. Claude Code, installed and authenticated

On your machine, not a demo of mine. Running, logged in, connected to your work. If a terminal isn't your thing, we set up the desktop app instead. Both work.

2. Your site in version control

Your website's code pulled into a GitHub repository you own. Every change from here forward is tracked, reversible, and reviewable. This is the single highest-leverage hour of the day, and it's the one nobody does on their own.

3. Claude connected to the repo

Claude reads your actual codebase. Not a description of it, not a paste of one file. It sees the whole thing and can change it.

4. Your first change, live

You describe a change in plain English. Claude writes it. You review it. It ships. You do this yourself, with me watching, before the day ends. The point is that you've done it once, so you believe you can do it again.

5. One agent, built and running

We pick this on the prep call from a short menu, so the afternoon is building instead of deciding. Options include a content agent that drafts in your voice from your own material, a research agent for prospects or competitors, a reporting agent that pulls your numbers on a schedule, an inbox triage agent, or a site agent that keeps a section of your website current.
